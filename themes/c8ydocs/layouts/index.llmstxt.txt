# Cumulocity documentation

> The official documentation for the Cumulocity IoT platform, covering both user and developer perspectives across device management, application enablement, analytics, and platform administration.

This file helps large language models navigate the Cumulocity documentation. Each entry under Documentation sets links to a focused llms.txt spoke for one topic area; llms-full.txt contains the complete documentation as plain text.
