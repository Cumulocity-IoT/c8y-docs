Skills are instructions for AI agents first and step-by-step guides for people second. Each skill solves one task, such as sending an operation to a device or managing trusted certificates, with the REST API requests it needs. Each request links to its operation in the {{< openapi >}}.

To give all skills to your AI agent, click **Download all skills**. You get a ZIP file with one folder per skill, each with a *SKILL.md* file, and a README file that describes how to install the skills and which credentials they need. Each topic below offers its own download, and each skill page has **Copy SKILL.md** and **Download skill**.

Documentation pages that have skills show them in a **Skills** tab.
