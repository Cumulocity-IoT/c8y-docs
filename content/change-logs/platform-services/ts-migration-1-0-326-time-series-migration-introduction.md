Starting in Q1 2025, the {{< product-c8y-iot >}} platform will include the Timeseries Migration application as part of the default set of subscribed microservices. This service will be automatically enabled for both existing and newly created tenants. The application facilitates the migration of tenant data from legacy Measurements to the new Timeseries storage. For more information, refer to [Time series migration](/standard-tenant/enhanced-time-series-support/#migration-process-description).
