**Deprecated user documentation**

The user & developer documentation for the releases 10.18.0 and 10.17.0 have been moved to the GitHub documentation repository. For details how to access it, see [Previous documentation versions](/about_documentation/documentation-repository/#product-documentation-for-previous-releases).

As a consequence, the entire content of the deprecated documentation website `https://cumulocity.com/guides/` has finally been deleted.

**Deprecated release notes**

The release notes for releases 10.18 and older, which have been provided at `https://cumulocity.com/releasenotes/`, have been archived. For details how to access it, see [Previous documentation versions](/about_documentation/documentation-repository/#product-documentation-for-previous-releases).

As a consequence, the entire content of the deprecated release notes website `https://cumulocity.com/releasenotes/` has finally been deleted.
