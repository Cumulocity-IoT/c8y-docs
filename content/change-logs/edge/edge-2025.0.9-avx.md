In previous versions of {{< product-c8y-iot >}} Edge, in order to properly support the embedded Mongo database, the installation process asserted that the CPU must support both AVX and AVX2 extensions. Edge could not be installed on a host where the CPU only supported AVX extensions.

This was incorrect, as the embedded version of Mongo only has a requirement for AVX extensions. The installation process has been modified, and Edge can now be installed on a CPU that only supports the AVX extensions and not the AVX2 extensions.
