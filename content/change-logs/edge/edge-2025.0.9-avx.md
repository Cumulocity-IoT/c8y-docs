In order to properly support the embedded Mongo database, previous versions of {{< product-c8y-iot >}} Edge asserted that the CPU must support both AVX and AVX2 extensions. Edge could not be installed on a host where the CPU only supported AVX extensions.

This was incorrect, as the version of Mongo embedded in Edge has a requirement for AVX extensions only. The installation process has been modified, and Edge can now be installed on a CPU that only supports AVX extensions.
