In previous Edge releases, the **c8yedge** installation could fail during K3s installation on systems where the `/tmp` directory was hardened with the `noexec` mount option. In such environments, the installation failed with a permission denied error when attempting to execute the K3s installation script from the `/tmp` directory. This issue has been resolved, and the installation now works correctly on systems with a hardened `/tmp` configuration.
