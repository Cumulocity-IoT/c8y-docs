When installing {{< product-c8y-iot >}} Edge with the **c8yedge** tool using an offline package, problems were sometimes observed when SELinux was enabled on the host system. This issue is dependent on the Linux distribution that is installed on the host system, but has been observed on Rocky Linux 8 and Alma Linux 10.

Firstly, c8yedge could attempt to download SELinux support packages from the internet, even if the customer had already installed them. Secondly, the K3s component used for hosting Edge could fail to start due to a permission error.

Both of these problems have now been fixed.
