You can now configure {{< product-c8y-iot >}} Edge to trust additional TLS certificates for external endpoints, in addition to certificates issued by public certificate authorities. This allows Edge to securely connect to endpoints such as a private registry hosting Edge artifacts or an SSO server used to authenticate users to tenants.

For details, see [Configuring trusted TLS certificates and proxy settings](/edge/installing-edge/#configuring-trusted-certs-and-proxy).
