In previous Edge releases, kubeconfig group assignment could be applied inconsistently under certain deployment conditions in **c8yedge** tool-based deployments, potentially resulting in unexpected access configuration behavior during cluster initialization. This issue has been addressed, and kubeconfig generation now applies group permissions consistently across supported deployment environments, improving the reliability of cluster provisioning and access management.
