This change resolves an issue where the {{< product-c8y-iot >}} Edge operator failed to trigger an upgrade for web applications. The operator's logic was flawed, preventing an upgrade when the size of the new application package was identical to the size of the currently deployed version. The operator now correctly identifies and applies updates based on the app version, resolving the upgrade failure.
