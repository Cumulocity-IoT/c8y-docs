Edge can now be installed using Helm charts and container images hosted in a private OCI-compliant registry. This is useful for organizations that require strict control over container image distribution. To support this, the **c8yedge** tool now includes the `registry-sync` command, which downloads the required artifacts and publishes them to a private registry.

For details, see [Install Edge operator from private OCI registry](/edge/installing-edge/#install-edge-operator-from-private-registry).
