{{< product-c8y-iot >}} Edge now deploys MQTT Service and Messaging Service as part of the default installation. These components are no longer optional and will be automatically included in all Edge deployments. 

As a result of this change, the minimum resource requirements for Edge deployments have increased. Ensure that your environment meets the updated resource specifications before upgrading or deploying.

For more details, see [Prerequisites](/edge/installing-edge/#prerequisites).
