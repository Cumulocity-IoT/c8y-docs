The **c8yedge** tool now supports installation and upgrade in an airgapped environment. After creating an offline package in a non-airgapped environment, you can ship it into your airgapped environment and install a new instance of Edge, or upgrade an existing instance of Edge.

For more details, see [Install Edge in an airgapped environment](/edge-kubernetes/installing-edge-on-k8/#install-edge-airgapped) and [Upgrading Edge in an airgapped environment](/edge-kubernetes/manage-edge/#upgrade-edge-airgapped).
