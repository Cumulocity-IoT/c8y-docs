As part of the 2026 release, the prerequisite requirements have been updated to support Kubernetes version 1.34.x in {{< product-c8y-iot >}} Edge.
If you manage your own Kubernetes cluster, you must ensure that your environment meets the updated prerequisites and upgrade your cluster accordingly to enable support.
If you are using the {{< product-c8y-iot >}} Edge tooling (**c8yedge**), the necessary changes are handled automatically as part of the upgrade process, and no additional action is required.
