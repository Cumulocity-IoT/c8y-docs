{{< product-c8y-iot >}} Edge now supports configuring the company name and administrator email via the Edge CR. The Edge CR is the source of truth. Changes made via the UI or {{< product-c8y-iot >}} API are overwritten by the Edge operator. To persist the changes, always update these fields in the Edge CR.

For details, see [Edge custom resource](/edge/edge-custom-resource-definition/).
