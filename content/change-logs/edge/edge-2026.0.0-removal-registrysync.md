To install and upgrade {{< product-c8y-iot >}} Edge in an airgapped environment, the only supported mechanism is now to use the **c8yedge** tool to create and install offline packages.

For more details, see [Install Edge in an airgapped environment](/edge/installing-edge/#install-edge-airgapped) and [Upgrading Edge in an airgapped environment](/edge/manage-edge/#upgrade-edge-airgapped).
