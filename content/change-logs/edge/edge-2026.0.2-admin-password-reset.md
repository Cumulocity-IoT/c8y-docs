In previous Edge releases, the `cumulocityPasswordSecretName` field of the Edge custom resource was immutable. Starting with this release, you can update this field to change the administrator password for both the {{< management-tenant >}} and the Edge tenant.

To change the password, either:
- Create a new Kubernetes secret containing the `C8Y_ADMIN_PASSWORD` key and update the `cumulocityPasswordSecretName` field in the Edge custom resource to reference the new secret.
- Update the existing referenced secret by adding the `C8Y_ADMIN_PASSWORD` key, if it does not already exist, or by updating its value.

For more information, see the description of the [cumulocityPasswordSecretName](/edge/edge-custom-resource-definition/#cumulocitypasswordsecretname) field.
