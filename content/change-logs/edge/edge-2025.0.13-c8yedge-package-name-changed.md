The **c8yedge** tool now includes the downloaded Edge version in the generated offline package filename (for example, `c8yedge-{{< c8y-edge-current-version >}}_0_0.tar`). This improvement allows for easier identification of package contents and prevents accidental overwrites when managing multiple versions.
