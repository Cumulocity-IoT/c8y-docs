Installing earlier versions of {{< product-c8y-iot >}} Edge did not require setting the initial admin password. Starting with this release, you must provide the initial password for the admin user during installation. This password is set for both the {{< management-tenant >}} and the Edge tenant.
When installing, provide the initial admin password either via the **c8yedge** tool's `--cumulocity-password` flag or by setting the Kubernetes Secret name in the Edge CR field `spec.cumulocityPasswordSecretName`.
