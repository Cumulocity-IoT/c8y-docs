Edge now supports Kubernetes version 1.36.x, which is the recommended version. Earlier Kubernetes versions are out of support or going out of support.

If you manage your own Kubernetes cluster, you are responsible for upgrading it to a supported version.

If you installed Edge using the **c8yedge** tool, upgrading Edge to version 2026.0.6 also upgrades Kubernetes ([K3s](https://docs.k3s.io/)). For details, see [Upgrading with the c8yedge tool](/edge/manage-edge/#upgrade-with-c8yedge).
