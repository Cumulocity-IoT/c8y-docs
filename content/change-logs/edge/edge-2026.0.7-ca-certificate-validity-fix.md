In previous Edge releases, if no external certificates were provided, the Edge operator generated self-signed CA certificates with a validity of 100 years. These certificates are also used for edge-to-cloud connectivity. The {{< product-c8y-iot >}} platform requires that self-signed CA certificates must not be valid for more than 5 years, which blocked new Edge registrations with the cloud. This issue has been resolved. The Edge operator now issues self-signed CA certificates with a maximum validity of 5 years.
