{{< product-c8y-iot >}} Edge on Kubernetes has been tested and is officially supported on Kubernetes versions 1.30.x, 1.31.x, and 1.32.x across supported platforms, including K3s, EKS, AKS, and upstream Kubernetes.
To upgrade your Kubernetes version, follow the official upgrade instructions for your platform. If you're using K3s, refer to the [K3 upgrade guide](https://docs.k3s.io/upgrades).
