{{< product-c8y-iot >}} Edge on Kubernetes has been tested and validated on Kubernetes version 1.32.x, the latest GA release at the time of product release. However, we support any CNCF-certified Kubernetes distribution that is still in active support, including K3s, EKS, AKS, and upstream Kubernetes.
To upgrade your Kubernetes version, follow the official upgrade instructions for your platform. If you're using K3s, refer to the [K3 upgrade guide](https://docs.k3s.io/upgrades).
