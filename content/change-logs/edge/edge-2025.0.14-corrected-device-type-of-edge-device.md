Previously, the {{< product-c8y-iot >}} Edge device was incorrectly identified in the cloud tenant with the device type `thin-edge.io`. This has been corrected to ensure proper identification as the device type is now set to `c8y_EdgeAgent`, which aligns with the firmware and the software management filters.

To manage, configure, and monitor your Edge remotely from your cloud tenant, refer to [connecting Edge to the cloud](/edge-kubernetes/k8-edge-connecting-edge-to-cloud).
