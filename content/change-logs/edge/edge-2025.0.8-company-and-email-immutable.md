In earlier releases, updating the `company` or `email` fields in the Edge Custom Resource (CR) after installation was technically allowed, but these updates were not reflected in the running Edge instance.

Starting with this release:
  - If the Edge was initially installed using the `c8yedge` tool, a subsequent update to these fields is permitted.
  - Any further modifications to these fields after the initial setup will now correctly trigger a validation error.

For more details, refer to the field descriptions in [Edge custom resource](/edge-kubernetes/edge-custom-resource-definition/).
