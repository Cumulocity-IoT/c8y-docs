In earlier releases, the `company` field in the Edge Custom Resource (CR) could be modified after installation. However, the change was not reflected in the Edge tenant details.

Starting with this release, the `company` and the `email` fields are now validated for immutability after installation. If Edge was initially installed using the **c8yedge** tool, subsequently setting these fields via the Edge CR is permitted only once. For more information, see the field descriptions in [Edge custom resource](/edge-kubernetes/edge-custom-resource-definition/).
