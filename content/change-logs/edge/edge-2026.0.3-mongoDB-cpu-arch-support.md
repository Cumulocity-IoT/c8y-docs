Starting with {{< product-c8y-iot >}} Edge `2026.0.3`, Edge deploys the Percona operator built on a UBI 10 base image. UBI 10 container images require the **x86_64-v3** (or newer) CPU microarchitecture and do not support older architectures. Before you create a new Edge deployment or upgrade an existing one to `2026.0.3` or later, verify that the CPU architecture of your Kubernetes nodes supports **x86_64-v3**.

For more information, see [Prerequisites](/edge/installing-edge/#prerequisites) and the [Red Hat Enterprise Linux Container Compatibility Matrix](https://access.redhat.com/support/policy/rhel-container-compatibility).
