The **c8yedge** tool now supports configuring Edge. After installing Edge with the **c8yedge** tool, you can also use this tool to perform post-installation configurations, for example, setting a custom domain, license key, SSL certificate, registering Edge in the cloud tenant etc.

For more details, see [Modifying Edge](/edge-kubernetes/manage-edge/#modify-edge).
