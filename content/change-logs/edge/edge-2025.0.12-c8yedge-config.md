The **c8yedge** tool now supports post-installation configurations. You can use the tool to configure a custom domain, license key, SSL certificate, register Edge in the cloud tenant etc.

For more details, see [Modifying Edge](/edge-kubernetes/manage-edge/#modify-edge).
