Analytics Builder models detect hierarchy changes within device groups. This includes additions of new devices, sub-groups, or assets, as well as updates, deletions, and structural changes in groups or assets. The model then processes data based on the updated structure, providing a seamless user experience.

For details, refer to [Device Hierarchy changes ](/streaming-analytics/analytics-builder/#group-hierarchy-changes).
