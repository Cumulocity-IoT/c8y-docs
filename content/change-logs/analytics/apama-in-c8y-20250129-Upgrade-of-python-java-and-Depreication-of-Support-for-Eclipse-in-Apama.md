The Python runtime shipped with Apama will be upgraded to version >=3.11 and the Java runtime will be upgraded to version Java 17. For details, see (the latest Apama change logs)[https://cumulocity.com/apama/docs/latest/change-logs] in the Apama documentation.
The next major releases of Apama will drop support for Windows. As a consequence, the Eclipse-based development environment will also be unavailable. This will affect the development and testing of EPL apps and Analytics Builder custom blocks natively on Windows.
