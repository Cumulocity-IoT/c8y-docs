Charts in applications built with the {{< product-c8y-iot >}} Web SDK show tooltips and legends that help you read the data in the "Data graph" widget and the data explorer. The compact tooltip now appears in a more consistent position and takes up less space on the chart. It also shows the time and date of the measurements it lists, which the compact view previously left out.
