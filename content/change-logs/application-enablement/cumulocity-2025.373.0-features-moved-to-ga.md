Several features that were previously available as Public Preview have now been promoted to General Availability (GA), indicating that they are fully production-ready and supported. The Data explorer offers enhanced data visualization capabilities, the Data point graph provides improved graph-based data representation, the HTML widget enables more flexible custom content display, and the Dashboard advanced tab unlocks additional dashboard customization options like import and export. With these features now in GA status, users can confidently utilize them in production environments with full support and stability guarantees, benefiting from the improvements and enhancements these new features bring.
