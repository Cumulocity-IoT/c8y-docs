The Codex design system now has a **Layout recipes** section. It includes an app shell guide and nine ready-to-use page layouts, such as entity detail, split view, dashboard, and full-page list, each with a live example. This section replaces the previous **Layout patterns** page.

This change only affects the Codex documentation. Applications built with the Web SDK are not affected.
