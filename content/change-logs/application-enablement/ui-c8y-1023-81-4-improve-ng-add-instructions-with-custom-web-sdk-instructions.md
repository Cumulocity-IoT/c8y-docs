When you create an app using the @c8y/websdk 'ng add' command, you are now prompted with a list of coding agents. Once selected, custom instructions tailored to your project will be added in format that matches agents of your choice. These instructions include project context, best practices, common implementation patterns, and guidance on where to find resources related to @c8y packages, helping you get started more quickly and follow recommended approaches from the start.
