Previously, the exports list view in the Cumulocity IoT platform was limited to displaying only the first 100 exports. To provide users with a more comprehensive overview of their available exports, the list view has been enhanced. It now shows up to 200 exports, doubling the number of visible entries. This improvement allows users to conveniently access and manage a larger set of their exports directly from the list view without the need for additional navigation or filtering steps.
