Digital Twin Manager previously supported only English and German, which
limited accessibility for users in other regions. The application now
includes translations for Chinese, Dutch, French, Korean, Polish,
Portuguese (Brazilian), and Spanish, bringing it in line with other {{<
product-c8y-iot >}} platform applications. Users in these regions can
now access Digital Twin Manager in their preferred language, improving
usability and reducing the need for manual translation workarounds.
