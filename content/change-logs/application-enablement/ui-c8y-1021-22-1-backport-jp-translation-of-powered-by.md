The "Powered by" text, which is displayed in the footer of Cumulocity IoT applications, was not properly translated to Japanese. With this change, the "Powered by" text is now still shown in English even when the language is set to Japanese. This change enhances the localization of Cumulocity IoT for Japanese users.
