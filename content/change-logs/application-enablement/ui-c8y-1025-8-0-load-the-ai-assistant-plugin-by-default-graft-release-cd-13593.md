The Assistant plugin provides a chat-based AI assistant that helps you find information and work with your Cumulocity applications. The plugin loads by default in the Cockpit application so that the AI Assistant is available as soon as you open the application. Other application can install the Assistant plugin via the [extensions](https://cumulocity.com/docs/standard-tenant/ecosystem/#extensions) capabilities. If you already loaded the plugin manually, you might need to remove the plugin from the extensions as otherwise it could get loaded twice.
