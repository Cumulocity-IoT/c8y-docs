The enhanced "SCADA" widget, previously available as a preview feature, is now generally available (GA).
The widget is built on web component technology with Lit syntax. It provides AI-assisted SVG generation, interactive placeholder mapping, flexible display settings, and an advanced editor.
For details, see [SCADA](/cockpit/widgets-collection/#scada) in the documentation.

Existing "SCADA" widgets that use AngularJS syntax continue to work in legacy mode. To reuse an existing SVG file in the new widget, follow the steps in [Migration from the legacy "SCADA" widget](/cockpit/widgets-collection/#migration-from-legacy-scada).
For more details on the enhancements, see the original [{{< product-c8y-iot >}} announcement](https://cumulocity.com/docs/change-logs/?productarea=.productarea-application-enablement-solutions&component=.component-cockpit&change-type=.change-type-feature#ui-c8y-1023-94-0-new-scada-widget-10388-graft-release-cd-12323).
