Alarm details in the {{< product-c8y-iot >}} application now support Markdown formatting, allowing you to use Markdown syntax (such as bold, italic, links, and lists) in the alarm descriptions shown in the alarm details. Previously, alarm text was displayed as plain text without any formatting options. With this improvement, you can now create more readable and structured alarm information that better communicates important details to your users. This enhancement applies to all existing and new alarms in your {{< product-c8y-iot >}} tenant, making alarm information more visually organized and easier to understand at a glance.
