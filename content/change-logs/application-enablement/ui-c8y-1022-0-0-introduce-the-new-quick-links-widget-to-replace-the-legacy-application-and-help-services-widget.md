Starting with version 1022.0.0, the "Quick links" widget replaces the legacy "Applications" and "Help & service" widgets. The "Quick links" widget provides configurable navigation items that can be customized through the widget configuration interface.

The widget supports the following configuration options:
- **Customizable links**: Add, remove, organize, and edit URLs, icons, and labels for navigation items
- **Layout options**: Grid, list, or card view modes
- **Tab control**: Configure whether links open in the current tab or a new tab
- **Reset functionality**: Revert to default settings or clear all custom configurations

To use the "Quick links" widget, add it from the widget catalog in your dashboard. The "Applications" and "Help & service" widgets are no longer available.

Existing dashboards using the legacy widgets will continue to function, but we recommend migrating to the "Quick links" widget to benefit from the improved configuration options.
