Previously, AI tool approvals that you approved or rejected looked different from other tool calls in the AI agent conversation, which made it harder to review what the AI agent did. Now, decided approvals appear in the conversation like other tool calls, so you can review the full history of tool calls in one consistent view. This update changes only how decided approvals are displayed and does not change how approvals work. Existing AI agents, tenants, users, and devices keep their current behavior, and you do not need to take any action.
