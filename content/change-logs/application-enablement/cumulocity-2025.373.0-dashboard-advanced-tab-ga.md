The Dashboard advanced tab, which was previously available as Public Preview, has now been promoted to General Availability (GA). This feature enables users to easily import and export dashboards, facilitating dashboard sharing and backup across different tenants and environments. With GA status, this functionality is now fully production-ready and supported, allowing users to confidently leverage dashboard import and export capabilities in production environments with full stability guarantees.
