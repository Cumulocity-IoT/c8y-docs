The x and y axis labels in charts were previously displayed using a default color that did not align with the applied branding. The axis labels now use the text-muted color, which provides better visual consistency with other secondary text elements in the application. This change improves the visual hierarchy and makes charts appear more cohesive with the rest of the user interface.
