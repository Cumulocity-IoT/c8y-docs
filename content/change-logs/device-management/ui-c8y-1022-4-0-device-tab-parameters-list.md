To provide a better overview of the device parameters, a new **Parameters** tab has been added to the Device Management application. This tab lists all parameters reported by the device in a table format, including the parameter name, value, type, and timestamp of the last update. With this change, users can now easily view and monitor device parameters without the need to navigate through measurements or the complete device data. The parameters list is automatically updated whenever new parameters are reported by the device.
