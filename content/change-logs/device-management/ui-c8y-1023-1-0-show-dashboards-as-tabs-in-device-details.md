Device dashboards as known from **Cockpit** are now available in **Device management** application. This allows users to create custom tabs for their devices on the device details page. Users can create template dashboards that automatically apply to devices of the same type, ensuring consistent views across their environment. Custom dashboards when created will replace the default **Info** tab.
