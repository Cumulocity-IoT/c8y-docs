The parameter list now automatically synchronizes to ensure displayed data remains current during active configuration. The interface triggers a refresh during common actions - such as receiving an event, updating an operation status, or navigating through rows and provides immediate interactive notifications to confirm when changes are complete. This update ensures a consistent and up-to-date view of parameters without requiring manual manual refreshes.
