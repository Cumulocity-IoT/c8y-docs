This feature is in Public Preview, that is, it is not enabled by default and may be subject to change in the future.
{{< /c8y-admon-preview >}}

You can now work with binary device payloads throughout the Data Preparation user interface. Test data inputs with a binary **Payload type** open in a hex editor, letting you view and edit the raw bytes alongside their ASCII representation, search by byte or ASCII sequence, and upload or download the payload as a file.

For details, see [Editing binary payloads](/data-preparation/rule-editor/#editing-binary-payloads).
