Introducing the new advanced settings under OPC UA server configuration that provide the option to enable auto-scan with either full or partial address space scan capabilities in Device management application.
Refer to [OPC UA - Connecting gateway to the Server](/device-integration/opcua/#connecting-gateway) section for more details.
This feature requires 1021.7.0 or higher version of opcua-device-gateway and opcua-mgmt-service components.
