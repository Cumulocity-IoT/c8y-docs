For LWM2M devices, it is now possible to adjust logging event level. It can be adjusted based on types or completely be disabled for the device. When enabled, log events are visible in the device's events. For more details see [LWM2M configuration](/protocol-integration/lwm2m/#lwm2m-configuration).
