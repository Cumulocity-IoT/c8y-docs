The **Measurements** tab in the device details has previously been updated to use the new data explorer. With this change the data explorer now gets pre-configured with all available data points of the displayed device. The first one is active by default, the rest are inactive. Users can change this in **Data point selector** by clicking the **Add data point** button.  The new **Measurements** tab replaces the old one if the **Data explorer** feature preview toggle is enabled.
