### Navigator {#navigator}

The navigator is an element on the left of the {{< product-c8y-iot >}} platform's UI. It provides a list of menu items that direct you to various pages within the [application](#application) currently in use.  

{{< c8y-details title="Developer details" >}}
The navigator is a UI component and does not have a direct REST API. It is extended using the Web SDK's `hookNavigator` provider to add new menu items (nodes).
{{< /c8y-details >}}  

### Notifications 2.0{#notifications-2.0}

[Notifications 2.0](/notifications) allows applications or microservices to reliably process realtime notifications generated by {{< product-c8y-iot >}}.
Notifications are published by the {{< product-c8y-iot >}} core and consumed by one or more microservices or external applications.
Delivery of notifications to consumers is guaranteed provided no [service quotas](/service-terms/quotas/#realtime-apis) are exceeded.

{{< c8y-details title="Developer details" >}}
Notifications 2.0 uses the [Messaging Service](#messaging-service) to decouple notification publishers from consumers.
Users can create multiple [topics](#messaging-service-topic) for the {{< product-c8y-iot >}} core to publish notifications onto.
Each topic can have one or more consumers, each of which will receive all of the notifications on the topic in the same order.
{{< /c8y-details >}}
