Protocol Gateway runs as a service of the thin-edge.io device, so you manage it on that device. The following tabs matter for Protocol Gateway. For more information on all tabs, see [Viewing device details](/device-management-application/viewing-device-details).

| Tab | Content for Protocol Gateway |
|-----|------------------------------|
| **Info** | Hardware and operating system information of the device. Do not store Protocol Gateway data here. |
| **Child devices** | One child device for each machine that Protocol Gateway reads. |
| **Services** | The container service, with start, stop, and restart commands. |
| **Software** | The Protocol Gateway software item and its version. |
| **Configuration** | The configuration types for the license file and for the Protocol Gateway configuration. |
| **Remote access** | Endpoints for SSH and for the Protocol Gateway web interface. |
