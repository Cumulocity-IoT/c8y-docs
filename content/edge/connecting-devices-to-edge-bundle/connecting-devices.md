Edge uses REST and MQTT as protocols for external communication. Both protocols may be used to interface devices with Edge. For more information, see [REST](/device-integration/device-integration-rest/) and [SmartREST 2.0](/smartrest/smartrest-two/).

Additionally, Edge supports OPC UA protocol through the OPC UA device gateway and OPC UA management service.
