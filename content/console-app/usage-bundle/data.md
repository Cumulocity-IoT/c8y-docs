The **Data** page gives you access to the raw underlying data that powers the graphs in the **Overview** page. It is simply a table with all the data, available for use with the same filters as the visualizations.

<img src="/images/console-app/usage/data/data.png" alt="Data">

The data is available on the tenant level. You can use the **Configure Columns** option to add or remove metrics from the table.

<img src="/images/console-app/usage/data/configure-columns.png" alt="Configure Columns">
