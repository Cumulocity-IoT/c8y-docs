Smart functions provide a lightweight way to extend the functionality of {{< product-c8y-iot >}} across multiple components. They let you write small Javascript functions that run in a secure, isolated environment—more powerful than configuration but much simpler than building a full microservice.

Use smart functions to process data, transform messages, create analytics, or customize behavior without managing complex deployment infrastructure. Whether you're preparing data before it enters the system, building analytics models, or processing messages at the edge, smart functions offer a unified approach with consistent security and performance.

Explore the topics below to understand how smart functions work across different components and when to use them for your use case.
