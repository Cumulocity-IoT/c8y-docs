A skill describes how to solve one task, such as sending an operation to a device or managing trusted certificates. It lists the steps, the REST API requests, and the expected results. Each step links to the operation in the {{< openapi >}}.

Documentation pages that have skills show them in a **Skills** tab.

Skills are written for people and for AI agents. To use them with an AI agent, click **Download all skills**. You get a ZIP file with one agent skill (a folder with a *SKILL.md* file) for each skill. The README file in the ZIP file describes how to install the skills and which credentials they need.
