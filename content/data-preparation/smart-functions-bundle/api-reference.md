The TypeScript API for Data Preparation smart functions is published as a public npm package: [`@c8y/dataprep-types`](https://www.npmjs.com/package/@c8y/dataprep-types). It contains type definitions for all input and output types, the context object, and the `onMessage` function signature. You can use it when developing and testing smart functions outside the platform.

The full generated API documentation is available at the [TypeDoc API reference](https://cumulocity-iot.github.io/datapreparation-rules-template/).

For information on developing rules in your own IDE with TypeScript support, version control, and CI/CD, see [External development](/data-preparation/external-development/).
