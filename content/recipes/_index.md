A recipe describes how to solve one task, such as sending an operation to a device or managing trusted certificates. It lists the steps, the REST API requests, and the expected results. Each step links to the operation in the {{< openapi >}}.

Documentation pages that have recipes show them in a **Recipes** tab.

Recipes are written for people and for AI agents. Each recipe is also available as Markdown: append `index.md` to its URL, or use the link at the end of the recipe. The Markdown version starts with a `name` and a `description`, so you can use it as a skill for an AI agent.
