The {{< product-c8y-iot >}} Web SDK is your toolkit for building powerful, scalable web applications on the {{< product-c8y-iot >}} platform. It provides secure API access, access to default UI components, and support for custom branding, allowing you to create tailored applications that seamlessly integrate with the platform’s ecosystem and maintain a consistent user experience.

For a detailed documentation, see the [{{< product-c8y-iot >}} Developers Codex](https://cumulocity.com/codex/).
