The **Data** page provides access to the raw underlying data that powers the graphs in the **Overview** page. It is simply a table with all data, available for use with the same filters as the visualizations.

<img src="/images/console/usage/data/data.png" alt="Data">

The data is available on the tenant level. You can use the **Configure columns** option to add or remove metrics from the table.

<img src="/images/console/usage/data/configure-columns.png" alt="Configure Columns">
