Tools extend the capabilities of AI agents by allowing them to perform actions such as querying device data, retrieving measurements, or accessing custom services. The AI Agent Manager supports built-in {{< product-c8y-iot >}} tools and custom tools via Model Context Protocol (MCP) servers.
