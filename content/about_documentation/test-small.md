Add the documentation as custom application to your tenant 

In the [Releases]({{< link-c8y-github >}}/c8y-docs/releases) section of the c8y-docs repository, select the release version and download the ZIP file (*c8y-guides-&lt;release-version&gt;.zip*) from the Assets list.
Log in to your Cumulocity tenant.
In the Administration application, navigate to **Ecosystem** > **Applications**.
Click Add application on the top right and select Upload web application.
Drop the downloaded ZIP file and follow the prompts to complete the upload.

Once uploaded, the application is created and available in the application list of your {{< product-c8y-iot >}} tenant.

#### Access the documentation in a web browser

1. In the [Releases]({{< link-c8y-github >}}/c8y-docs/releases) section of the c8y-docs repository, select the release version and download the ZIP file (*c8y-guides-&lt;release-version&gt;.zip*) from the Assets list.
2. Open the zip file in a browser.
3. Double-click the file named index.html in the root folder. It will open in your default browser.
